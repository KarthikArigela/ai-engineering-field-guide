## Additional Podcast Leads

- [Data Engineer Career in 2026: Roles, Specializations, and What Companies Look For](https://www.youtube.com/watch?v=bTHhvKMursI) - Slawomir Tulski. Personal projects are weaker than work examples but still count; choose projects based on target specialization; for platform-side data engineering, build a toy end-to-end data platform.
- [Learning Machine Learning Self-Taught Bioinformatics](https://www.youtube.com/watch?v=Kc3Puh3UCRQ) - Aaisha Muhammad. Balance theory and projects; projects expose gaps theory does not; dataset-first ideation can work when the data is genuinely interesting.
- [Open Source ML Contributions](https://www.youtube.com/watch?v=IxV9EH-tphQ) - Vincent Warmerdam. Side projects and community work caught Rasa's attention and led to a role; good GitHub docs need install, problem, contribution info, examples, guides, API reference; OSS contributions and talks are a plus.
- [Analytics to Data Science with Kaggle Portfolio](https://www.youtube.com/watch?v=ixmTewD5Waw) - Andrada Olteanu. "Look at my Kaggle profile" is stronger than just saying "I know Python"; GitHub, homepage, or blog can also work.
- [Competitions Beyond Kaggle Leaderboard](https://www.youtube.com/watch?v=oRxT4AWkQVM) - Tatiana Gabruseva. A competition can become a portfolio project via a clean GitHub repo with README; one repo helped get an offer.
- [Data Science Career ABC Framework](https://www.youtube.com/watch?v=HVQ0DZOQcts) - Danny Ma. Project portfolio is one of the most important assets; public projects let recruiters and hiring teams see what you can do.
- [Hugging Face Contributions and NLP Portfolio](https://www.youtube.com/watch?v=SnEYvF-Ztb8) - Merve Noyan. Use Streamlit, Gradio, or Hugging Face Spaces demos; recruiters will not clone a repo and run models.
- [Hiring Data Scientists and Analysts](https://www.youtube.com/watch?v=WSMDXsjKYx4) - Alicja Notowska. Course portfolio projects are nice to have; experience with models/tools matters more, but completing work still says something.
- [How to Become AI Engineer After Career Break](https://www.youtube.com/watch?v=IwG_JaxC-Y8) - Revathy Ramalingam. Telecom capstone; startup asked for GitHub and scheduled interview after seeing portfolio projects.
- [Hiring for Data Engineering Jobs in Europe](https://www.youtube.com/watch?v=hylxiu4VGTo) - Nicolas Rassam. GitHub is reviewed if shared, but candidates need to explain projects clearly and in detail.
- [Job Search Strategy in Tech: Projects, Skills, CV, Networking](https://www.youtube.com/watch?v=PchwbIs0tOg) - Sarah Mestiri. Avoid endless courses; do focused projects; pick target companies to decide projects; put practical projects high on CV; share small GitHub work while learning.
- [From Software Engineer to Machine Learning](https://www.youtube.com/watch?v=xVYOdRrN7hw) - Santiago Valdarrama. Do not only consume courses; produce something; many useful projects do not require ML.
- [Practical DevRel: Demo-first Education and Open Source](https://www.youtube.com/watch?v=vXbMUfHE1OE) - Will Russell. Hackathons teach Git, teamwork, building/deploying real projects; demo/presentation is a key project component.
- [Nonlinear Path to Machine Learning, Freelancing, and Public Learning](https://www.youtube.com/watch?v=5km62e4nDaw) - Pastor Soto. Two capstones paid off; deployed AWS projects still serve as proof of work.
- [Get Data Analytics and Data Engineering Job](https://www.youtube.com/watch?v=0wANfIvum4U) - Gloria Quiceno. Repeated bootcamp projects tire employers; individualized projects with clear motivation stand out.
- [Product Designer to Data Product Manager](https://www.youtube.com/watch?v=nt__pVuuC-k) - Sara Menefee. Build public case studies around data products: problem, research, solution, outcome.
- [How to Stand Out in Data Science](https://www.youtube.com/watch?v=RhSg8ill1So) - Marijn Markus. Unique projects beat copying common Kaggle work; coffee-machine time-series project became portfolio evidence.
- [Data Interview Behavioral and Portfolio Prep Guide](https://www.youtube.com/watch?v=tRdLVUKU7Bo) - Nick Singh. Be ready to deep-dive a favorite portfolio/side project; quantify impact; link GitHub/project in targeted outreach.
- [From Math Graduate to Data Analytics](https://www.youtube.com/watch?v=qh6-HDhw2xY) - Juan Pablo Murillo. Any portfolio is better than none; GitHub is fine, but make it easy with good descriptions and clean README.
- [Get Data Engineering Job Prep and Interview](https://www.youtube.com/watch?v=asnt7xlyZXQ) - Jeff Katz. Personal projects plus OSS show code quality; data engineering portfolio should emphasize Python/SQL and can include open-source work.
- [How to Break Into Data Science](https://www.youtube.com/watch?v=oUycqtMoYr8) - Misra Turp. Beginner projects should show critical thinking, data issues, tool choice; prefer real-life datasets over Titanic/Iris.
